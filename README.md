# virtual-AI-assistant

Overview
This project is a simple Virtual AI Assistant built using Python. The assistant utilizes speech recognition to understand voice commands and text-to-speech to respond to the user. It can perform various tasks such as playing music, telling the current time and date, and providing information from Wikipedia.

Features
Voice Recognition: Listens for user commands using the speech_recognition library.
Text-to-Speech: Responds to user queries with spoken responses using the pyttsx3 library.
Music Playback: Plays songs on YouTube using the pywhatkit library.
Information Retrieval: Fetches summaries from Wikipedia based on user queries.
Time and Date: Provides the current time and date upon request.
